SECTION 01 // EFFICIENCY ANALYSIS

Why Binary Search Beats Linear Search

In a Linear Search, you check every single element one by one. If your item is at the end of a list of 1 million items, you're making 1 million comparisons.


Binary Search, however, divides the problem into smaller sections. By constantly dividing the list in half, it reaches the target much faster. For a list of 1 million items, Binary Search finds the target in under 20 comparisons.

SECTION 02 // ALGORITHM LOGIC

Understanding the Algorithm

Binary Search only works on sorted arrays. The logic follows these steps:

01
Find the Middle
Look at the element in the center of the current range.
INIT
02
The Match
If the target is the middle, then it's completed.
SUCCESS
03a
Target Smaller — Go Left
If the target is smaller than the middle, throw away the right half and repeat the search on the left.
HALVE
03b
Target Larger — Go Right
If the target is larger, throw away the left half and repeat on the right.
HALVE
04
Repeat
Keep halving the search area until the target is found or the range becomes empty.
LOOP

SECTION 03 // RECURSIVE APPROACH

Implementing Binary Search Using Recursion

Recursion is an easy way to understand binary search as the problem breaks down into smaller versions of itself. It does this by calling itself in the function itself.

Python binary_search_recursive.py 
def binary_search_recursive(arr, low, high, target):
    # Base case: the range is exhausted
    if high >= low:
        mid = (high + low) // 2
        # If element is present at the middle
        if arr[mid] == target:
            return mid
        # If element is smaller than mid, search the left subarray
        elif arr[mid] > target:
            return binary_search_recursive(arr, low, mid - 1, target)
        # Else search the right subarray
        else:
            return binary_search_recursive(arr, mid + 1, high, target)
    else:
        # Element is not present in array
        return -1

SECTION 04 // ITERATIVE APPROACH

Iterative Binary Search

Another way to do a binary sort is an iterative function, instead of calling it itself, the iterative function does it manually by using a while loop until the number is found.

Python binary_search_iterative.py 
def find_index(data, target):
    """
    An efficient iterative binary search function.
    Returns the index of target if found, else -1.
    """
    left = 0
    right = len(data) - 1
    while left <= right:
        # Calculate mid (using this formula prevents overflow in some languages)
        mid = left + (right - left) // 2
        
        if data[mid] == target:
            return mid  # Found it!
        
        if data[mid] < target:
            left = mid + 1  # Target is in the right half
        else:
            right = mid - 1 # Target is in the left half
    return -1 # Target not found
